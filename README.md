# 提示词随机生成器（AI Prompt Generator）

一个**纯前端、无需后端**的 AI 绘画提示词随机生成工具。内置分类词库（**38 个分类、1583+ 条中英文词条**），一键随机抽取类别与词条，辅助快速组合出多样化的人物 / 场景提示词，适合 Stable Diffusion 等 AI 绘画工作流。

页面默认展示全部词库，可自由选中、锁定、屏蔽，偏好自动保存在浏览器本地。

## 目录结构

```
├── index.html   # 页面
├── data.js      # 词库数据
└── app.min.js   # 页面逻辑（压缩混淆版）
```

## 🚀 使用方式

### 本地使用

无需安装任何环境，**双击 `index.html`** 即可在浏览器中打开使用。

> 若浏览器以 `file://` 打开时屏蔽记录无法保存（部分浏览器限制），可用任意静态服务器（如 `python -m http.server`）在本地方便地跑起来。

### 部署到服务器

把整个目录上传至任意静态服务器即可：Nginx / Apache / GitHub Pages / 对象存储 / VPS 均可，无需任何后端与数据库。

- Nginx：将文件放入站点根目录，无需额外配置
- GitHub Pages：仓库根目录放这三个文件，在 Settings → Pages 开启即可
- 保证三个文件在同一目录下即可，无路径依赖

## ✨ 功能特性

### 🎲 随机生成
- **随机类别数 / 每类词条数** 两个参数自由设定
- 生成一次后调整"随机类别数"立即生效：
  - **增加**类别 → 自动从未选类别中补充新类别
  - **减少**类别 → 弹窗选择「随机取消」或「手工取消」（手工模式可精确勾选要移除的类别）

### 🖱️ 灵活的词条交互
- **点击词条**切换选中 / 取消，右侧输出框实时联动
- 未选中词条以浅色小样式显示，与选中状态明显区分
- **锁定（🔒）**：上锁的词条在重新随机时保留不动
- **屏蔽（⛔）**：被屏蔽的词条不再参与任何随机
- **锁定所有已选**：一键锁定当前全部选中词条
- **分类级屏蔽**：屏蔽整个分类（自动清空该类选中与锁定），不参与随机

### 💾 本地持久化
- 屏蔽的分类 / 词条自动保存到浏览器 `localStorage`
- 下次打开页面无需重新屏蔽
- 「重置」按钮 + 「清除屏蔽」复选框可一键清空

### 📝 输出
- 可自定义**前置提示词**（默认 `masterpiece,best quality,...`），始终位于输出最顶部
- 输出框每行一个类别、词条以英文逗号分隔、行尾自动补逗号
- 一键复制到剪贴板

## 🖥️ 界面布局

- **左侧**：全部分类与词条卡片，每个词条带锁定/屏蔽按钮
- **右侧**：输出面板（sticky 固定），实时显示生成的提示词
- **顶部**：参数设置（类别数 / 词条数）、生成 / 锁定 / 重置按钮、前置提示词编辑框

## 🔒 隐私说明

- 所有数据与操作均在浏览器本地完成，**不上传任何数据**
- 词库随页面静态加载，无外部 API 请求
- 屏蔽偏好仅存储在你本地浏览器的 `localStorage` 中
