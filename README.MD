# 提示词随机生成器（AI Prompt Generator）

> #### 🍷 本工具可能不适合在工作场合打开
>
> 有些灵感，只适合在深夜酝酿；有些词库，只适合在环节干净的浏览器里悄悄打开（记得开无痕模式，懂的都懂）。骰子一摇，几百个词随机登场——至于摇出来的组合是用于学术研究、艺术创作，还是某种不可名状的浪漫冒险……工具一概不问，也概不负责。命运掌握在你自己手里，术语表掌握在骰子手里。

纯前端、无需后端的 AI 绘画提示词随机生成工具。内置 **38 个分类、1583+ 条中英文词条**，适合 Stable Diffusion 等 AI 绘画工作流。双击 `index.html` 即可使用。

## ✨ 功能一览

| 功能 | 说明 |
|------|------|
| 🎲 一键随机生成 | 自定义「随机类别数」和「每类词条数」，一键抽出类别与词条 |
| 📂 类别数动态调整 | 生成后修改类别数立即生效：增加自动补抽新类；减少时可选「随机取消」或「手工勾选取消」 |
| 🔒 词条锁定 | 单条锁定后，重新随机时该词条保留不动；支持「锁定所有已选」 |
| ⛔ 词条屏蔽 | 屏蔽不喜欢的词条，永久不参与随机（保存在浏览器本地） |
| 🚫 分类屏蔽 | 一键屏蔽整个分类，清除该类所有选中与锁定状态 |
| 💾 偏好持久化 | 屏蔽的分类/词条自动保存到 localStorage，下次打开无需重新设置 |
| 📝 前置提示词 | 可编辑的提示词前缀（默认 `masterpiece,best quality,...`），始终输出在开头 |
| 📋 实时输出 | 右侧输出面板实时联动，每行一个类别、逗号分隔、行尾补逗号，一键复制 |
| 🌐 中英对照 | 每个词条同时显示英文原文与中文释义 |

## 🎲 随机生成

- 两个参数自由设定：**随机类别数**、**每类词条数**
- 打开页面默认展示全部词库，可先浏览再随机
- 生成后再次点击「生成提示词」：
  - 已**锁定**的词条原样保留
  - 已**屏蔽**的词条与分类自动排除
  - 其余词条重新随机，补齐到设定数量
- 调整「随机类别数」：
  - **调大** → 自动从未选分类中补抽新类别
  - **调小** → 弹窗选择取消方式：
    - 🎲 **随机取消**：直接随机移除多余的类别
    - ✅ **手工取消**：精确勾选要移除的类别（配额校验，选够才能确认）

## 🔒 锁定与屏蔽

### 词条级
- 每个词条右上有**锁定按钮**：上锁后重新随机不丢失（金色高亮）
- 每个词条左上有**屏蔽按钮**：屏蔽后变红加删除线，不再出现在随机结果中
- 「🔒 锁定所有已选」按钮：一键锁定当前全部选中词条

### 分类级
- 每个分类标题左侧有**屏蔽按钮**：屏蔽时自动清除该类全部选中与锁定
- 「重置」按钮旁有「**清除屏蔽**」复选框：
  - 勾选后重置 → 彻底清空所有状态（含屏蔽）
  - 不勾选重置 → 只清选中/锁定，**保留屏蔽偏好**

## 📝 输出与复制

- 输出面板固定在页面右侧，内容**实时联动**每一次点击
- 格式：每行一个类别，词条以英文逗号分隔，行尾自动带逗号
- 顶部前置提示词一键包含，可直接粘贴进 Stable Diffusion 使用
- 「复制」按钮一键复制全部内容

## 🚀 使用

无需安装，双击 `index.html` 即可；或把三个文件（`index.html` / `data.js` / `app.min.js`）上传到任意静态服务器（Nginx、GitHub Pages、对象存储等）。
